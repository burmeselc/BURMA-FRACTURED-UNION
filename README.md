# BURMA: FRACTURED UNION

**近現代ミャンマーの国家形成・民族自治・政治経済・内戦を扱ふ、ブラウザ向け歴史大戦略シミュレーション（開発中）。**

独立直後の1948年から現代までを長期的な対象とし、議会政治、地方統治、社会階層、武装組織の分裂・統合、外交、停戦などを相互に作用させることを目指します。史実を出発点としながら、史実の結末は強制しません。

> **Current playable prototype: v1.5 — BURMA 1948: Union at the Crossroads**  
> 1948年1月〜12月の連邦政府を操作する試作。現在は開発・検証段階です。

## 起動・プレイ

- **[ゲーム本体（index.html）](./index.html)** をダウンロードして、Chromiumなどのブラウザで開いてください。外部ライブラリ・サーバーは不要です。
- ブラウザ内保存とJSON形式のセーブ書出・読込に対応します。
- このリポジトリのソースは公開済みですが、**GitHub Pagesでのプレイ用サイトは別途有効化が必要**です。管理者は **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** を選択してください。有効化・配信完了後の想定URLは `https://burmeselc.github.io/BURMA-FRACTURED-UNION/` です（現在アクセスできることを保証するものではありません）。

## v1.5で操作できること

- 月次ターンで1948年を進め、農地・徴税・教育・自治・政治交渉などの政策を選ぶ。
- AFPFL、CPB、PVO、KNU、シャン州の政治層、国軍などの行動・関係変化を閲覧する。
- 全国14の分析地域と、シャン州内12の地方政治単位を確認する。
- 地方政治AI、地域内の協議・競合、州制度上の政策審議を試す。
- 統一主体台帳（初期59主体・43関係）を検索する。
- 分岐した展開を記録・保存する。

**未実装**：他勢力へのプレイ切替、精密な歴史GIS、実際の人口・経済統計を用ゐた計算、全国の全勢力、1949年以降の連続キャンペーン、軍事部隊を操作する戦争システムなど。

## 歴史資料と試作パラメータ

本作では次を明確に区別します。

1. **史実**：史料・研究で確認された出来事・組織・制度。
2. **推定**：出典からの推測で、確実でないもの。
3. **抽象化**：ゲーム上の計算のためにまとめた地域・社会集団。
4. **仮定値**：信頼度・資金・緊張度・勢力関係などの試験用係数。

現在の初期係数や政策効果は、1948年の実測統計や歴史的発生確率を示しません。地域概略図は史実の行政境界・領域支配を示す精密地図ではありません。民族・言語・宗教により個人の政治的忠誠を自動的に決定する設計は採りません。
