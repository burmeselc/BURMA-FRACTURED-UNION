# BURMA: FRACTURED UNION

1948年のビルマ連邦から現代に至る国家形成・民族自治・政治経済・内戦を主題とする歴史大戦略シミュレーション（**開発中**）。史実を出発点としながら、政治的選択による架空史への分岐を扱ひます。

**現在の試作：BURMA 1948 v1.6**。1948年の12か月を、連邦政府の立場から操作できます。数値・影響力・政策効果には仮定値が含まれ、史実の勢力圏や支持率を示すものではありません。

## プレイ

- **[GitHub Pagesでゲームを開く](https://burmeselc.github.io/BURMA-FRACTURED-UNION/)**。配信反映には時間が掛かる場合があります。
- 通信なしの単一ファイルで遊ぶ場合は、[`dist/burma_1948_standalone_v16.html`](dist/burma_1948_standalone_v16.html) をダウンロードし、ブラウザで開いてください。
- 進行状態はブラウザ内に保存でき、JSONとしてバックアップ・復元できます。初期カタログの取得を除き、プレイ状態を外部サーバーには送信しません。

## v1.6 の内容

月次ターンで政策、財政、州自治交渉を選択。AFPFL、CPB、PVO、KNU、国軍などのAI、全国14分析地域、シャン州の12政治単位、地域内の政治主体、政治的関係と州制度審議を扱ひます。統合台帳で59件の主体と関係を検索・確認できます。各主体の史実・制度・分析用モデル・架空史の区別と、動的な分裂系譜も表示します。

今回から、組織・人物・地域・制度・関係の初期データは外部JSONで管理します。史料校閲を進めながらデータを増補できます。
